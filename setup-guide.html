Google Vision APIキーの取得方法

手書き文字を自動判定するために必要です。
無料でできます！（月1000回まで）

1

Google Cloudにアクセスしてアカウントを作成する

まず、Googleアカウント（Gmailなど）でログインします。
👉 https://console.cloud.google.com/ を開く

初めての場合は「無料で開始」ボタンをクリックして、クレジットカードを登録します。

💳 クレジットカードは必要？ 登録は必要ですが、このアプリで使う「Vision API」は毎月1000回まで無料です！ 練習で使う分には料金はかかりません。
2

新しいプロジェクトを作成する

1. 画面上部の「プロジェクトを選択」をクリック
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を入力（例：pref-app）して「作成」

プロジェクト名の例: pref-study-app
3

Cloud Vision API を有効にする

1. 左上のメニュー（☰）から「APIとサービス」→「ライブラリ」をクリック
2. 検索ボックスに「Cloud Vision API」と入力
3. 「Cloud Vision API」をクリックして「有効にする」ボタンをクリック

✅ 有効にするを押すと、数秒後に 有効 と表示されます。
4

APIキーを作成する

1. 左上のメニューから「APIとサービス」→「認証情報」をクリック
2. 画面上部の「＋ 認証情報を作成」→「APIキー」をクリック
3. しばらくするとAPIキーが表示されます（AIza...で始まる文字列）
4. コピーボタンをクリックしてコピーする

例: AIzaSyBxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
⚠️ APIキーはひみつ情報です！
他の人に教えたり、SNSに載せたりしないようにしてください。
5

APIキーの利用制限を設定する（おすすめ）

安全のために、APIキーが使えるサービスを制限しましょう。

1. 作成したAPIキーの「編集」をクリック
2. 「APIの制限」で「キーを制限する」を選択
3. リストから「Cloud Vision API」を選んで保存

💡 こうすることで、もしキーが漏れても Vision API 以外には使えなくなります。
6

アプリにAPIキーを入力する

アプリの手書き判定を使おうとすると「APIキー設定」ダイアログが表示されます。
そこにコピーしたキーを貼り付けて「保存する」をクリックしてください。

これで手書き文字の自動判定が使えるようになります！🎉

⚙️ config.js で直接設定する方法
アプリフォルダの config.js を開いて、
VISION_API_KEY: '' の部分に直接キーを入力することもできます。
例：VISION_API_KEY: 'AIzaSy...'

料金について

Cloud Vision API の料金（2024年現在）：

・月 1,000回まで無料（無料枠）
・1,001回〜 : 1,000回あたり約1.5ドル（約230円）

お子さまの学習用途では、1日10〜20回使っても月300〜600回程度。無料枠で十分です！

心配な場合は、Google Cloud のコンソールで「予算アラート」を設定しておきましょう。
